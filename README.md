# Shrimp

一个 Chrome 扩展示例：它会从你配置的本地 URL 拉取坐标，然后只保留坐标附近区域的正常显示，其余页面内容会被轻微降亮、降对比度，并把 RGB 视觉上压低一点。

## 使用方式

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，指向这个仓库目录。
4. 点击扩展图标，填写本地坐标接口地址，例如 `http://127.0.0.1:3000/coordinate`。
5. 第一次使用某个来源时，浏览器会弹出该来源的访问授权请求，允许后才能读取坐标。

## 本地接口格式

扩展会尽量兼容几种常见返回格式：

- JSON 对象：`{"x": 320, "y": 240}`
- 嵌套对象：`{"coordinate": {"x": 320, "y": 240}}`
- 数组：`[320, 240]`
- 文本：`320,240`

如果接口返回的是文档坐标，可以在弹窗里把“坐标基准”切换成 `document`。默认是 `auto`，会先按视口坐标处理，再在必要时尝试按文档坐标解释。

如果接口没有返回坐标，扩展会直接使用当前鼠标光标的位置作为输入；如果页面上还没有记录到鼠标移动，则会先用屏幕中心作为临时焦点。
