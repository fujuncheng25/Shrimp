# Shrimp

一个 Chrome 扩展示例：它会从你配置的本地 URL 拉取坐标，然后只保留坐标附近区域的正常显示，其余页面内容会被轻微降亮、降对比度，并把 RGB 视觉上压低一点。

## 使用方式

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，指向这个仓库目录。
4. 点击扩展图标，填写本地坐标接口地址，例如 `http://127.0.0.1:3000/coordinate`。
5. 第一次使用某个来源时，浏览器会弹出该来源的访问授权请求，允许后才能读取坐标。

## 本地接口格式

扩展会尽量兼容几种常见返回格式：

- JSON 对象：`{"x": 320, "y": 240}`
- 嵌套对象：`{"coordinate": {"x": 320, "y": 240}}`
- 数组：`[320, 240]`
- 文本：`320,240`

如果接口返回的是文档坐标，可以在弹窗里把“坐标基准”切换成 `document`。默认是 `auto`，会先按视口坐标处理，再在必要时尝试按文档坐标解释。

如果接口没有返回坐标，扩展会直接使用当前鼠标光标的位置作为输入；如果页面上还没有记录到鼠标移动，则会先用屏幕中心作为临时焦点。

## 三种预设模式（可调）

扩展内置三种自动切换的阅读模式，并且支持在弹窗 UI 中手动调参数与触发条件：

- Focused Reading（默认）
	- 默认启用。
	- 会把焦点范围外的区域压得更暗，强化中心区域。
- Scanning Mode
	- 当光标持续快速移动 1200ms 后触发。
	- 焦点外区域会变得更亮一些，便于快速扫读。
- Fatigue State
	- 当光标长时间低活动（长时间几乎不动）并保持很慢速度时触发。
	- 整体变化会更慢，且焦点外区域比 Focused Reading 更暗。
	- 一旦光标移动变快，会自动退出并回到 Focused Reading。

你可以在弹窗里直接调整：

- Focused/Scanning/Fatigue 各自的亮度倍率、对比倍率、饱和倍率、暗层倍率、外围文字倍率、过渡倍率。
- Scanning 和 Fatigue 的速度阈值、触发时长、退出条件，以及速度衰减相关参数。
